Scanner Worksheets

Print these pages (or copy them into a notebook) and keep them next to the scanner. They turn a sprawling "digitize everything someday" project into repeatable, finishable sessions.

Worksheet A: Collection Inventory

Fill one per box, album, or envelope before scanning anything.

Collection name: ________________________________
Storage location found: __________________________
Type (circle all): prints / slides / negatives / album pages
Approximate count: ______
Date range (best guess): ________ to ________
Condition notes (mold? tears? stuck together?):
________________________________________________
________________________________________________
Fragile items needing flatbed only (count): ______
Priority (1 = do first): ______
Date logged: ____________

Why: you cannot plan sessions or estimate time without knowing what's in each box. Inventory first also means that if the project stalls for a year, you still know what you have.

Worksheet B: Session Plan

Fill one per scan session. A session is 1–3 hours, one event or one box.

Session date: ____________
Target collection (from Worksheet A): ____________________
Tool today (circle): phone / flatbed / light pad
Lighting setup (circle): window / two lamps / LED jig
Resolution (circle): 300 dpi / 600 dpi        (see ch. 3)
File format (circle): TIFF masters / JPEG only
Naming batch prefix: YYYY-MM-DD_event  → ____________________
Starting sequence number: ______
Time budget: ______ hours

Why: decisions made before the first capture (tool, light, dpi, naming) are consistent; decisions made photo-by-photo are chaos.

Worksheet C: Batch Log

One line per batch of photos within a session.

Batch # | What's in it            | Count | Done | Glare check | Named
--------|-------------------------|-------|------|-------------|------
  1     | 4x6 prints, reunion box |  38   | [ ]  |    [ ]      | [ ]
  2     | 3x5 prints, same box    |  22   | [ ]  |    [ ]      | [ ]
  3     |                         |       | [ ]  |    [ ]      | [ ]
  4     |                         |       | [ ]  |    [ ]      | [ ]

Check "Glare check" only after zooming to 100% on a few samples (chapter 2's self-check). Check "Named" only after the batch is renamed per chapter 4 — same session, never "later."

Why: the log is what lets you stop mid-project without losing your place.

Worksheet D: Session Close-out

The last five minutes of every session. Do not skip.

[ ] All captures renamed (years-and-events, zero-padded)
[ ] Event folder created in masters/ tree, notes.txt written
[ ] Files copied to external drive #1
[ ] Batch log completed
[ ] Next session's target written here: ____________________
[ ] Anything damaged during handling? Note it: _____________

Why: the close-out is the backup habit. A session that ends without the copy step is a session that can be lost.

Worksheet E: Verification Record

Twice a year, per chapter 6.

Date: ____________
Drive checked: ____________
Random files opened OK: 10 / 10?  [ ]
Folder count matches masters: [ ]
Off-site copy refreshed this visit: [ ]
Off-site drive returned to: ____________________
Next verification due: ____________

Printing these worksheets

This page is plain Markdown — print it from any viewer, or use the built site's print-friendly layout (every page prints cleanly; worksheets render as monospace blocks that hold their alignment on paper).

A pre-filled example of Worksheet B for a typical first session:

Session date: 2026-11-08
Target collection: Grandma's shoebox #1 (inventory #1)
Tool today: phone
Lighting setup: window
Resolution: 300 dpi
File format: TIFF masters
Naming batch prefix: → 1974-12-00_christmas
Starting sequence number: 001
Time budget: 2 hours

That's a complete, realistic Saturday morning: 40–80 prints captured, named, filed, and backed up before lunch.
